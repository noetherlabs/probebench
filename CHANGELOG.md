# Changelog

## 0.0.1 — 2026-10-14

- Add a six-mode, monochromatic Fourier reference, bounded OPD actions, photon/read noise
  and an explicit controller-observation/evaluator boundary.
- Add development phase-diversity, coordinate-search, random-probe and no-action policies.

  complete tables and a figure demonstrating defocus ambiguity and diagnostic probing.

This is a development foundation, not a completed benchmark, agent comparison or public
release. The final statistical protocol, robust estimator, isolated agent interface,
budget curves, replay explorer and Hugging Face release are still in progress.
