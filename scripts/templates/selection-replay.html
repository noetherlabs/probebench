Model, display and source evidence

This is a public parameter-selection cohort. Every candidate is retained, including settings not selected as references. Related conjugates, detector replicates and shared budget prefixes do not add independent wavefronts. These data do not establish held-out rankings, hardware performance or language-model capability.

The model is static, monochromatic scalar Fourier optics with a circular pupil, six OPD modes, and Poisson–Gaussian detector noise. The estimator assumes exactly matched calibration. Commands are optical path difference; ideal reflective surface displacement is half that value.

Display: log1p(max(measured electrons, 0)) / log1p(photons per exposure), magma colour map, fixed limits 0–1, image origin lower. Display clipping leaves the original signed float64 measurements unchanged. A submitted final command can match an earlier exposure, the last exposure, or no exposure at all.

This portable replay reads copied PNG files beside this page and requires no external service. Its generator checks the derived export against a trusted manifest fingerprint; it does not rerun the native physics. A checksum establishes file consistency, not authorship.
