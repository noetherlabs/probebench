# Classical reference selection v1

This packet freezes the six classical reference settings selected from a completed
public tuning study: 4,032 episodes, 30,912 exposures, 14 candidates and 12 independent
base wavefronts. Read the [results and limitations](../../docs/parameter-selection-results.md)
and the [selection protocol](../../docs/parameter-selection.md).

## Two evidence inventories

| File | Contents |
| --- | --- |
| `study.json` | Exact executed configuration, numerical runtime and source hashes |
| `preparation.json` | Exact generated cohort, member identities and exclusion checks |
| `summary.json` | Every episode's retained outcome and numerical diagnostics |
| `selection.json` | All 14 losses and the full cell/stratum/base/member/replicate reduction |
| `selected-settings.json` | Six selected candidate IDs and their complete policy configurations |
| `source/` | The 21 unchanged source and dependency files used by the acquisition |
| `archive-manifest.json` | Original manifest of the separately distributed complete native archive |
| `release.json` | Distribution checksums, source identity and verification scope |
| `evidence.json` | Descriptive candidate and diagnostic aggregates with scientific limits |
| `fit-diagnostics.json` | All-start and selected-fit counts for every candidate |
| `figures/` | Candidate losses and curves generated from `selection.json` |
| `packet-manifest.json` | Separate SHA-256 inventory of the files in this compact packet |

The compact packet does **not** contain detector arrays or full episode records.
Its manifest has a different purpose from the native study manifest. The original
`archive-manifest.json` is renamed here because it describes the external archive,
not the local subset.

Check packet consistency and reproduce the complete selection reduction:

```sh
uv run --locked python scripts/verify_selection_release.py \
  results/classical-selection-v1-20261016
```

This checks the packet inventory, the independently pinned native manifest, original
copied bytes, source hashes, all 4,032 outcome identities, the reduction and complete
selected configurations. It does not verify camera data that are absent from the packet.
Figures and descriptive summaries are checked against the packet's declared hashes;
their scientific interpretation is not established by a checksum.

## Download and replay the complete archive

The [tagged release](https://github.com/noetherlabs/probebench/releases/tag/classical-selection-v1-20261016)
provides `classical-selection-v1-20261016.tar.gz` and its SHA-256 checksum. Download the
attached dataset asset, rather than GitHub's automatically generated source-code archive:

```sh
mkdir -p downloads
gh release download classical-selection-v1-20261016 --repo noetherlabs/probebench \
  --pattern classical-selection-v1-20261016.tar.gz --dir downloads
python3 - <<'PY'
import hashlib
import json
from pathlib import Path

release = json.loads(Path("results/classical-selection-v1-20261016/release.json").read_text())
package = Path("downloads") / release["archive"]["filename"]
digest = hashlib.sha256()
with package.open("rb") as handle:
    for chunk in iter(lambda: handle.read(1024 * 1024), b""):
        digest.update(chunk)
if (package.stat().st_size != release["archive"]["bytes"]
        or digest.hexdigest() != release["archive"]["sha256"]):
    raise SystemExit("Archive checksum or size mismatch; do not extract")
print("Archive checksum and size match the release record.")
PY
```

Obtain this repository's release record from a trusted revision. A checksum establishes
consistency with that record; it does not authenticate a record obtained from an
untrusted source. After the check succeeds, extract into a new directory and replay:

```sh
mkdir downloads/selection-native
tar -xzf downloads/classical-selection-v1-20261016.tar.gz -C downloads/selection-native
uv run --locked python scripts/verify_selection_release.py \
  results/classical-selection-v1-20261016 \
  --archive downloads/selection-native/classical-selection-v1-20261016
```

The distributed tar contains regular files with normalized ownership and timestamps.
`LICENSE` and `NOTICE` sit beside the native directory. Every native file remains
byte-identical to the completed study, including its manifested, empty `.lock` file.
Keep dependencies, generated bytecode, plots and reports outside that directory.

Full verification checks every native file and replays detector draws, saved-fit policy
commands and physical metrics. The verifier imports only a temporary copy of the
independently hash-pinned source from this packet; it does not execute arbitrary source
from the downloaded archive. It does not refit the optical model. The recorded numerical
environment is Python 3.11.15, NumPy 2.4.6 and SciPy 1.17.1 on macOS arm64. No
cross-platform bitwise optimizer-reproduction claim is made.

Recompute the optimizer-start diagnostics without rerunning optimization:

```sh
mkdir -p work
uv run --locked python scripts/summarize_selection_fits.py \
  --archive downloads/selection-native/classical-selection-v1-20261016 \
  --output work/selection-fit-diagnostics.json
```

The destination must be new and outside the archive. This diagnostic command binds
every case JSON to the published native manifest and checks complete case/start
accounting; it does not perform optical replay or hash the detector arrays.

## Source and interpretation

The acquisition source corresponds to public revision
[`705e31e`](https://github.com/noetherlabs/probebench/tree/705e31e00325d5c0648cdc6161ed2ba2c338c666).
Its canonical 21-file source-inventory digest is
`9dc4c5901e54b73e129f93e94b977df7e02bf8e32cddecd47014d51c09e8aff0`.
The snapshot preserves the acquisition implementation and predates later hardening;
use the current repository for general development. Do not replace snapshot files
with current files while claiming identical acquisition provenance.

The selected settings are conditional on twelve public tuning bases, the candidate
grid and equal cell/stratum weighting. They are not held-out performance estimates or
evidence about hardware, model mismatch or language-model competence. The sequential
HTML replay and ImageFolder exporters do not support this selection archive.
